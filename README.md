
# Python Calculator

## Project Description
A simple menu-driven calculator developed using Python.
It performs basic arithmetic operations based on user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exponentiation
- Division by zero handling
- Continuous calculations

## Technologies Used
- Python 3
- Functions
- Loops
- Conditional Statements
- Exception Handling
- Arithmetic Operators

## How to Run
1. Install Python 3.
2. Download the project.
3. Open the terminal in the project folder.
4. Execute:

python calculator.py
